# Auto-Translate

Bu proje, Selenium kullanarak otomatik olarak web sayfalarındaki içerikleri birden fazla dile çevirmek için geliştirilmiştir. Özellikle e-ticaret sitelerinde veya çok dilli içerik yönetim sistemlerinde kullanılmak üzere tasarlanmıştır.

## 🚀 Özellikler

- CKEditor gibi metin editörlerindeki içeriği otomatik çevirme
- Form alanlarında yer alan başlık, açıklama, vs. gibi verileri çevirme
- Python + Selenium tabanlı yapı
- Birden fazla dil seçeneğiyle kolay çeviri
- Manuel müdahale olmadan otomatik iş akışı

## 🧰 Gereksinimler

- Python 3.9+
- Google Chrome ve uygun ChromeDriver
- pip ile kurulu gerekli kütüphaneler
